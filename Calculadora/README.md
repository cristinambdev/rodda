# Calculadora de terminal

Calculadora interactiva para usar desde la terminal, escrita en Python 3.

## Ejecutar

Desde esta carpeta:

```bash
python calculadora.py
```

En Windows tambien puedes usar:

```bash
py calculadora.py
```

El menu permite sumar, restar, multiplicar, dividir, calcular raices cuadradas y consultar el historial de operaciones.
